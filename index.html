Vierzehn Tage.
Vier Etappen.

Kein „Wir melden uns". Sie wissen an jedem Tag, wo Ihr Projekt steht — vom ersten Gespräch bis zum Go-Live.

  1. Tag 1

    Kickoff

    Ein Gespräch, 60 Minuten — per Telefon oder WhatsApp. Danach weiß ich, was Ihr Betrieb braucht. Und Sie wissen, was Sie bekommen.

  2. Tag 2–6

    Design

    Konzept und Gestaltung, zugeschnitten auf Ihre Branche und Ihre Kunden. Erste Vorschau nach fünf Tagen, erste Feedback-Runde inklusive.

  3. Tag 7–12

    Code

    Jede Zeile von Hand: HTML, CSS, JavaScript. Kein Theme, kein Plugin-Zoo — dafür unter 2 Sekunden Ladezeit und Security auf A+.

  4. Tag 13–14

    Go-Live

    Zweite Feedback-Runde, letzter Check, online. Dazu ein Workshop, damit Sie Texte und Bilder künftig selbst pflegen können.
